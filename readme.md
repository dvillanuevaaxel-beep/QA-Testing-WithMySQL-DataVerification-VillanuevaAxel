# QAT Toolkit: Data Entry Verification with MySQL

## Repository Overview

This QAT (Quality Assurance Testing) toolkit documents the functional testing of an AI-generated PHP web application, "Kara David's Wish Note", with backend validation performed through MySQL queries.

**Repository contents:**

- **Part A:** `readme.md`, this file, containing the test case for the AI-generated web application.
- **Part B:** `webapp-generation-prompt.txt`, the AI prompt used to create the test web application.
- **Part C:** `test-webapp.php`, the single-file PHP web application generated by AI.

The original test case document is saved as `textcase.txt` (also referred to as `TestCase.txt` in the course material).

## Defect Report

| Field | Details |
|---|---|
| **Defect** | The Location value is not saved to the database. |
| **Affected column** | `Location` in table `main_corrupt_politicians` |
| **Observed** | The form accepts a Location, the modal displays it, and the app shows a success message, but Location is NULL in every stored row. |
| **Cause** | The INSERT statement is `INSERT INTO main_corrupt_politicians (FirstName, LastName, GovPosition) VALUES (?, ?, ?)`. It omits the Location column and the matching `bind_param` value. |
| **Severity** | Medium. Data is silently lost and the user is told the operation succeeded. |
| **Expected fix** | Add `Location` to the column list and to `bind_param`: `INSERT INTO main_corrupt_politicians (FirstName, LastName, GovPosition, Location) VALUES (?, ?, ?, ?)`. |
